# Atrim for Linux
This is a launcher for the atrim client, a custom client for Amnesia: The Dark Descent. The launcher is a simple, rudimentary qt6 application written in C++.

**Keep in mind that you need a legal copy of Amnesia: The Dark Descent in order to use both the launcher and the client needed to play the game. Cracked copies may work but are neither tested nor supported.**

To use it you will need to specify your Amnesia: The Dark Descent install folder. Then, this downloads the latest client files from the atrim GitHub repository. While doing so this will also automatically backup your Amnesia: The Dark Descent install folder.

Like the client, this will work with any copy of the game, including but not limited to GOG.com, Steam, DVD, Epic Games Store, Humble Bundle, etc. Read the warning above regarding cracked copies.

Right now it only supports Linux at the moment but the actual source code is universal and can be compiled manually as a single application for almost every distribution or OS that supports the qt6 framework (or has the qt6 shared library).

Currently it is tested on CachyOS/Arch Linux but it should work on any distribution that supports AppImages.
